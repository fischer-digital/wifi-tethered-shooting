## English

Thank you for your interest in contributing! This repository contains documentation and handles issue tracking for the WiFi Tethered Shooting Studio app.

### Ways to Contribute

#### 1. Camera Setup Guides (most wanted!)

We test cameras we have access to, but there are many WLAN-FTP capable cameras out there. If you've successfully used the app with a camera that isn't documented yet, please share your setup!

**How to contribute a camera guide:**

1. Copy the template: [`docs/en/camera-setup/TEMPLATE.md`](docs/en/camera-setup/TEMPLATE.md)
2. Fill in your camera-specific settings and experience
3. Add screenshots if possible (save to `images/cameras/`)
4. Submit a Pull Request

#### 2. Translations

- Improve existing English documentation
- Translate English docs to other languages
- The app currently supports German and English

#### 3. Bug Reports

Use the [Bug Report](../../issues/new?template=bug-report.md) issue template. Please include:

- Device model and Android version
- Camera model
- Steps to reproduce
- Expected vs. actual behavior

#### 4. Feature Requests

Use the [Feature Request](../../issues/new?template=feature-request.md) issue template.

### Pull Request Guidelines

- For camera guides: use the provided template
- Keep one topic per PR
- Add screenshots where helpful
- Test your markdown renders correctly on GitHub

## Deutsch

Vielen Dank für dein Interesse an einem Beitrag! Dieses Repository enthält die Dokumentation und das Issue-Tracking für die WiFi Tethered Shooting Studio App.

### Möglichkeiten zum Mitmachen

#### 1. Kamera-Anleitungen (am meisten gesucht!)

Wir testen Kameras, die uns zur Verfügung stehen, aber es gibt viele WLAN-FTP-fähige Kameras. Wenn du die App erfolgreich mit einer noch nicht dokumentierten Kamera nutzt, teile bitte dein Setup!

**So trägst du eine Kamera-Anleitung bei:**

1. Kopiere die Vorlage: [`docs/de/camera-setup/TEMPLATE.md`](docs/de/camera-setup/TEMPLATE.md)
2. Fülle die kamera-spezifischen Einstellungen und Erfahrungen aus
3. Füge wenn möglich Screenshots hinzu (speichere in `images/cameras/`)
4. Erstelle einen Pull Request

#### 2. Übersetzungen

- Verbessere die bestehende deutsche Dokumentation
- Übersetze deutsche Anleitungen in andere Sprachen
- Die App unterstützt derzeit Deutsch und Englisch

#### 3. Fehlerberichte

Nutze die [Bug Report](../../issues/new?template=bug-report.md) Vorlage. Bitte gib an:

- Gerätemodell und Android-Version
- Kameramodell
- Schritte zur Reproduktion
- Erwartetes vs. tatsächliches Verhalten

#### 4. Feature-Wünsche

Nutze die [Feature Request](../../issues/new?template=feature-request.md) Vorlage.

### Pull-Request-Richtlinien

- Für Kamera-Anleitungen: nutze die bereitgestellte Vorlage
- Ein Thema pro PR
- Screenshots wo hilfreich
- Überprüfe, dass dein Markdown auf GitHub korrekt gerendert wird
