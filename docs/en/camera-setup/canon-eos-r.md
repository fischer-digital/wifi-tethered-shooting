## Expected Settings (Based on Canon FTP Documentation)

Canon EOS R cameras with WLAN-FTP support should work with the following general settings:

| Setting | Value |
|---|---|
| FTP Server / Host | Your device's IP (shown in the app) |
| Port | `2121` |
| Username | `anonymous` |
| Password | *(leave blank)* |
| Transfer Mode | Passive |

### General Canon Menu Path

1. **Menu** → **Communication Settings** → **FTP Transmission Settings**
2. Configure the FTP server details
3. Enable **Auto Send** for automatic transfer

> ⚠️ These are estimated instructions. Please verify with your specific model and [submit corrections](../../../CONTRIBUTING.md).
