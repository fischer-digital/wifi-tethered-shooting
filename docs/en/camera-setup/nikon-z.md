## Expected Settings (Based on Nikon FTP Documentation)

Nikon Z cameras with WLAN-FTP support should work with the following general settings:

| Setting | Value |
|---|---|
| FTP Server / Host | Your device's IP (shown in the app) |
| Port | `2121` |
| Username | `camera` (default, adjustable in app settings) |
| Password | Auto-generated (shown in app, adjustable in settings) |
| Transfer Mode | Passive |

### General Nikon Menu Path

1. **Menu** → **Setup Menu** → **Connect to FTP Server**
2. Configure the FTP server details (connection settings)
3. Enable **Auto Send** for automatic transfer after each shot

> ⚠️ These are estimated instructions. Please verify with your specific model and [submit corrections](../../../CONTRIBUTING.md).
