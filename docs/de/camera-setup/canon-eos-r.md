## Erwartete Einstellungen (Basierend auf Canon FTP-Dokumentation)

Canon EOS R Kameras mit WLAN-FTP-Unterstützung sollten mit folgenden allgemeinen Einstellungen funktionieren:

| Einstellung | Wert |
|---|---|
| FTP-Server / Host | IP deines Geräts (wird in der App angezeigt) |
| Port | `2121` |
| Benutzername | `anonymous` |
| Passwort | *(leer lassen)* |
| Übertragungsmodus | Passiv |

### Allgemeiner Canon-Menüpfad

1. **Menu** → **Kommunikationseinstellungen** → **FTP-Übertragungseinstellungen**
2. FTP-Server-Details konfigurieren
3. **Auto-Senden** für automatische Übertragung aktivieren

> ⚠️ Dies sind geschätzte Anweisungen. Bitte mit deinem spezifischen Modell überprüfen und [Korrekturen einreichen](../../../CONTRIBUTING.md).
