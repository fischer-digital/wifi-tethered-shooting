## Erwartete Einstellungen (Basierend auf Nikon FTP-Dokumentation)

Nikon Z Kameras mit WLAN-FTP-Unterstützung sollten mit folgenden allgemeinen Einstellungen funktionieren:

| Einstellung | Wert |
|---|---|
| FTP-Server / Host | IP deines Geräts (wird in der App angezeigt) |
| Port | `2121` |
| Benutzername | `camera` (Standard, in App-Einstellungen änderbar) |
| Passwort | Automatisch generiert (wird in der App angezeigt, in Einstellungen änderbar) |
| Übertragungsmodus | Passiv |

### Allgemeiner Nikon-Menüpfad

1. **Menu** → **Einrichtungsmenü** → **Mit FTP-Server verbinden**
2. FTP-Server-Details konfigurieren (Verbindungseinstellungen)
3. **Auto-Senden** für automatische Übertragung nach jedem Foto aktivieren

> ⚠️ Dies sind geschätzte Anweisungen. Bitte mit deinem spezifischen Modell überprüfen und [Korrekturen einreichen](../../../CONTRIBUTING.md).
